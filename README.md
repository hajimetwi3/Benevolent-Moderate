## Benevolent Moderate
Benevolent Moderate : 善意の穏健なひと

人、AI、動物などは、善意で穏健で中立、
バイアスの無い方が良いんじゃないかなって個人的には思っています。  
君はどう思うかな？  

私はこう思っているけど、それでもバイアスがかかっている時もあると思う。  
常に内省し、自分に何かバイアスがかかっていないか考える事ぐらいしかできていないけど、
それでも足しにはなると考えてる。  
君はどう思う？  
  
こういうことを考えると不安になるかもしれないけど、
それが私が進むべき善意で穏健、中立な道だと信じている。  
一般的にはどうなんだろうね？
